## 02 — Keyboard decision logic (NO IMAGE — compiles into a dynamic Quiz)

- **Do NOT generate an image.** The keyboard decision flow (structure → connection → switch) is written as structured logic in the body and is compiled by the user's web tool into an interactive Quiz.
- **Logic summary (for the Quiz builder):**
  1. **Structure:** Gasket (soft, less finger fatigue) if you type a lot → Tray/classic (cheaper) if occasional / budget-first.
  2. **Connection:** Tri-mode (multi-device) if you switch devices → Single if one device.
  3. **Switch:** Linear (quiet, long sessions) if shared office → Tactile (feedback) if own room.
  - Tie-breaker: when unsure, pick hot-swappable.
- **Language:** 100% English, zero Chinese (Quiz UI).
